# ActiveTAG Configurator v0.8.2

- Uses the stable `ActiveTAG-Configurator.exe` filename for builds and updates.
- Automatically migrates installations updated from v0.8.0 or v0.8.1 away from versioned EXE names.
- Keeps version information in the window title and Windows file metadata.
- Publishes compatibility assets so older updater versions can install this release.
