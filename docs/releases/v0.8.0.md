# ActiveTAG Configurator v0.8.0

- Checks the public GitHub repository for a newer release after startup.
- Shows a native Dear ImGui update prompt with release notes.
- Downloads updates into the current application folder without requiring setup.
- Verifies every downloaded EXE against its published SHA-256 checksum.
- Uses a temporary copy of the application as the updater, then starts the new version.
- Leaves the current application untouched if download or verification fails.
