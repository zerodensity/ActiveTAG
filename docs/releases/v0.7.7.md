## Safe RF Channel Default

- Starts the editor with RF Channel set to `15` when the application opens.
- Keeps the RF Channel dropdown locked to the validated `11-26` range.
- Reading a connected ActiveTAG still replaces the editor default with the
  device's actual RF Channel value.
